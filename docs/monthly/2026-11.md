# 2026-11 · `epiCore` 与端到端示例

首个发布周期：先把契约层做成正式 R 包，再用一条薄而完整的链路证明各层能接上。

| 项 | 内容 |
|---|---|
| 版本 | `v0.1`（月内修订 `v0.1.1`） |
| 包 | `epiCore` 0.1.0 |
| 层 | L0 契约、L6 编排 |

## 交付

- `epi-core/`：契约 schema、地区编码、邻接权重、`read_counts()`、质控、周期映射；40 项单测。
- `vertical_slice/run_e2e.R`：合成数据跑通 L0 → L6，产出预警清单与单文件 HTML 报告。
- `pipeline.R` + `R/pipeline_plan.R`：分层计划、输入指纹缓存、统一 manifest、静态报告站。
- `tests/smoke_e2e.R` 与 `tests/golden/`：27 项指标 + 10 项结构断言的集成基线。
- `demo/make_demo_data.R`：固定种子的合成面板、邻接、SES 与月度轴，供所有示例与 CI 使用。

## 示例链路的结果

R 4.6.0、零第三方依赖、固定种子 `20261110`。

```
L0  16 地区 4×4 格网，原始面板 4161 行
L1  质控剔除 2 行（重复 1 / 缺失 1），清洁契约表 4159 行
L2  832 组季节性基线带，816 期评估，56 条异常信号，注入的 6 周暴发全部命中
L3  rook 权重 16×16，Moran's I = 0.441，999 次置换 p = 0.031
L4  集中指数 -0.067，低/高 SES 报告率比 1.23
L5  单文件 HTML，3 张内联 SVG 与 3 张表，断网可开
L6  run_manifest.json 与阶段缓存
```

面板示例（31 个 `D01`–`D31` 地区 × 21 年）：最新年合计 2131 例对历史中位数 6449 例，单侧升高预警 0 条；单年 Moran's I = 0.406（p = 0.003），多年累积 0.858（p = 0.001）；集中指数 -0.113。数据里注入了长期下降趋势与 SES 空间梯度，所以「趋势导致零命中」「空间集聚」「不平等」三条支路都有输出可看。

## 设计决定

- **L2–L5 写成适配器**，调用成熟的包而不重写算法；INLA / Stan 等重型依赖放 `Suggests`，只装 base R 也能跑完链路。
- **契约只有一个版本源**：`epi-core/inst/contract/schema.json`，其余位置不复制。
- **示例数据全部合成**：地区编码不对应任何真实行政区，数值由固定种子生成，结论只用于演示方法。

## 已知限制

- 面板示例为地区-年粒度；月度示例用合成数据走通接口，换成真实月度 CSV 只需改 `--monthly` 参数。
- 六层中的 L2–L5 仍为薄实现，后续按月替换为独立包。
