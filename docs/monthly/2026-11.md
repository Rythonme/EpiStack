## 1. 本月目标

原计划是「传染病监测周报一键生成器」（单点工具）。经判断，单点工具撑不起「每月一个 GitHub 项目」的目标，于是升级为 **EpiStack 六层体系**；同时为规避「先造半年零件、最后拼不起来」，定下核心策略：

> **第一个月就打通一条薄而全的 L0→L6 链路，之后每月只替换某一层的实现，上下游契约不变。**

本月要证明的是：这条链路**今天就能在本机一条命令跑通**，且换成正式 R 包后口径不变。

## 3. 实测结果（R 4.6.0，零第三方依赖）

### 3.1 合成数据六层切片

```
L0  epi-core    16 地区 4×4 县级格网，原始面板 4161 行
L1  epi-ingest  质控剔除 2 行（重复 1 / 缺失 1）；清洁契约表 4159 行
L2  epi-alert   832 组季节性基线带；816 期评估；56 条异常信号；注入的 6 周暴发全部命中告警
L3  epi-space   rook 权重 16×16；Moran's I = 0.441，999 次置换检验 p = 0.031
L4  epi-ineq    集中指数 CI = -0.067；低/高 SES 报告率比 = 1.23
L5  epi-report  单文件 HTML（3 张内联 SVG + 3 张表，断网可开）
L6  epi-flow    run_manifest.json + 4 个阶段缓存，固定种子 20261110
```

替换 L0/L1 为 `epiCore` 正式包后，**以上数值逐位不变**。

### 3.2 模拟数据演示与本机私有验收

| 指标 | 结果 |
|---|---|
| 模拟面板 | 31 个 `D01`–`D31` 地区 × 21 年 = 651 行，质控 **剔除 0 行**；合成邻接 + 合成 SES（沿格网呈空间梯度） |
| 最新年样本合计 | 2131 例 vs 历史中位数 6449 例（**−67.0%**）→ 单侧升高预警 **0 条** |
| Moran's I | 单年 **0.406 (p = 0.003)**；多年累积 **0.858 (p = 0.001)** |
| 集中指数 CI | −0.113；低/高 SES 组率比 1.45 |

模拟面板刻意注入了长期下降趋势与 SES 空间梯度，因此 Moran's I 显著、CI 为负，便于演示「趋势 → 预警零命中」「空间集聚」「不平等」三条支路的完整输出。本机另用私有面板完成过一次端到端验收（数据与结果不公开），其诊断结论已写入本地报告，不在公开仓库中复述。

## 5. 踩坑与关键决策

| 问题 | 处理 |
|---|---|
| 6 地区格网空间检验功效不足（p = 0.699） | 改 4×4=16 地区并让 SES 呈空间梯度 → p = 0.031，同时保留 CI 负值 |
| 本机私有面板只有地区-年粒度，月度面板仅气候协变量 | 不拿推算值冒充月度实测：公开版本改用内置模拟数据完整演示月度链路，`read_counts()` 粒度可配置，拿到月度直报 CSV 后一键切换 |
| 邻接图节点顺序必须与地区列表一致 | `epi_read_graph()` 按节点序号映射；模拟生成器与适配器统一使用 `sort(unique(...))` 顺序，并新增「质控全剔除」的明确报错 |
| `R CMD check` 在中文路径 + locale 下失败 | 纯 ASCII 临时路径 + 清除 `LC_ALL/LANG/LC_CTYPE`；测试脚本由 `requireNamespace()` 改为 `library()` |
| Windows 中文路径经命令行传给 Rscript 子进程乱码 | 编排/冒烟在同一 R 会话内 `source(..., local=new.env())`，只靠环境变量注入路径 |
| 缓存 state 在 `cached` 阶段被覆写成空对象 | 以旧 state 为底、只覆盖真正重跑过的阶段 |
| `sprintf` 占位符数量、JSON 序列化空向量 | 回归中捕获并修复 |

**关键架构决策**：L2–L5 一律写成**适配器**，调用清单里已成熟的包（不重写算法）；INLA / Stan / GeoAI 放 `Suggests`，保证断网、只装 base R 也能端到端跑通。
