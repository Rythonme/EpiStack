## 设计决定

- **统计量与切片逐位一致**：`I = (n/S0)·Σw_ij z_i z_j / Σz_i²`，置换用 `replicate(n_perm, I(sample(x)))`，p 用 `(1 + #{|I_null| ≥ |I_obs|}) / (n_perm + 1)`。换包不换数，slice 的 Moran 一项没动。
- **历史排序与正确对齐分开**：切片原来的 `tot` 是 `merge` 后的字典序，与权重矩阵的地区顺序不同。为保 golden，切片继续把无名向量交给 `space_moran()`；包本身默认按权重矩阵的地区名对齐，独立演示走这条正确口径，两种口径在文档里分开写明。
- **结构对称才算有效权重**：行标准化后 `W[i,j]` 与 `W[j,i]` 可以因度数不同而不同，但邻接结构必须对称；孤立地区直接报错，不静默补 0。
- **不显著不分类**：HL / LH 且显著才叫空间离群，不显著一律「不显著」，避免把随机波动当地点。
- **BYM2 是模板不是拟合**：INLA 放 Suggests，函数只生成数据清单、邻接图代码与模型代码，不写文件、不调用外部程序。

## 已知限制

- 只做单期空间格局描述，不做时空交互，也不做病因推断。
- 地区数少（n < 20）时置换 p 的分辨率有限，999 次置换最小只能到 0.001。
- LISA 未做多重比较校正，地区多时应自行控制假阳性。
- 权重定义直接决定结论：换 rook / queen 或换邻接图都要重新解释，报告里必须写明用的哪一种。
- BYM2 模板的先验与 offset 需按病种和样本量核对，不能直接引用为最终模型。
